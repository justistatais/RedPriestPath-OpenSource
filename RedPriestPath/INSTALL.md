# 安装、升级与卸载

## Windows 安装

1. 退出《文明 VI》。
2. 将发布包中的 `RedPriestPath` 整个目录复制到：

   `%USERPROFILE%\Documents\My Games\Sid Meier's Civilization VI\Mods`

3. 确认最终文件直接位于：

   `...\Mods\RedPriestPath\RedPriestPath.modinfo`

4. 启动游戏，在“附加内容”中启用模组，以“风云变幻”规则集创建新游戏。
5. 在“高级设置”选择“《诡秘之主》模组语言”：默认为简体中文，需要英文时改为English。该设置控制本模组全部游戏内文本，开局后不可更改。
6. 如需测试四座封印城和阶段3圣者／天使，在同一高级设置的“游戏模式”组勾选“拯救模式”。不勾选时不会加载拯救模式坐标、城市、阶段3数据库或Gameplay脚本。
7. 进入地图后，在首回合弹窗中选择“红祭司途径”、“完美者途径”、“黑皇帝途径”或“本局不启用”；每名人类玩家独立选择，三条途径不可同时生效。

其他系统请使用该平台《文明 VI》的用户 Mods 目录，并保持同样的单层目录结构。

## 升级

退出游戏后，用新版本完整替换旧 `RedPriestPath` 目录。不要混合保留旧 Lua/XML 文件。
`0.1.0-rc.40` 使用状态结构版本 25，能够迁移已经启用任一途径的旧版存档；既有红祭司存档不会改选为完美者。状态25会同步重建仍存活的持有者，保留经验、老兵名、生命值和剩余移动力，但会清除旧侦察晋升，因为官方Gameplay API只有授予晋升接口而没有移除接口；死亡待复活持有者也会清空旧晋升快照。旧版完美者仍会切换为金色专属内部单位类型。阴谋家及后续序列可重新选择谋划目标；旧存档首次读取只建立当前战争基线，不会因已经存在的战争追发2000金币。若载入rc.35中已处于谋划战争的存档，状态迁移会补挂原版每回合100金币Modifier。rc.29/30中已经晋升序列0但尚无过场序号的完美者存档，会补排一次完美者专属过场；点击顶部完美者入口后播放，点击“继续”确认。rc.26/27中完美者遗物若已经增加内部计数却未真正生成，仍会按该计数补挂V3原版遗物Modifier。两条途径从序列1晋升序列0时，已建立真神教会使用正常成本项目，未建立则改用生产力需求翻倍的无圣项目。真实旧存档迁移仍是待实测项。
升级前应备份存档和旧模组目录。

## 卸载

退出游戏，在“附加内容”中禁用模组，然后移走或删除 `Mods\RedPriestPath`。依赖该模组
创建的存档可能拒绝载入或失去途径内容；卸载不负责改写存档。

## 故障日志

Windows默认日志目录：

`%LOCALAPPDATA%\Firaxis Games\Sid Meier's Civilization VI\Logs`

排查时保留：

- `Database.log`：XML/SQL schema、重复Type和外键问题。
- `Modding.log`：modinfo、依赖、Action和文件加载。
- `Lua.log`：UI Lua错误。
- `Lua.log`：生命周期、消化、晋升、纵火及UI载入日志。

复现前先退出游戏并归档旧日志，再用新游戏复现一次。搜索 `LOTM_RP`、`ERROR`、
`Runtime Error` 和 `no such`。双客户端证据可用
`Tests/collect_multiplayer_evidence.ps1` 分别收集后再比较。

# 互联网 / LAN 双客户端验收脚本

本脚本必须由两套真实《文明 VI》客户端执行。任何未完成用例保持 `[ ]`，不得只凭静态
验证改为通过。建议先跑 LAN，再以同一构建跑互联网。

  完美者/完美者、红祭司/完美者、任一途径/`NONE`。
- [ ] 开启同时回合。每个检查点保存屏幕、存档及
  `Database.log`、`Modding.log`、`Lua.log`、`GameCore.log`及`net_*_debug.log`。
- [ ] 用 `collect_multiplayer_evidence.ps1` 生成双方日志 SHA-256 清单。

# 资源422普通模式验收

本清单需要用户在游戏中执行。Lua替身、SQLite演练、构建和哈希检查只支持对应离线结论。

完全退出游戏后重启。新普通局进入高级选项，在中英文切换旁确认“AI邪教难度”可选简单、困难、疯狂，默认简单。救赎局不显示此项。单机和联机均需核对中英文；开局后不能改变。旧档固定视为简单，原邪教归属、阶段和首次谋划奖励记录保留。

| 红祭司场景 | 预期 |
|---|---|
| 猎人攻击满血非蛮族 | 无条件战斗加成 |
| 攻击蛮族、受伤敌军、受伤蛮族 | 都是一次+15；移动+2、视野+5和地形通行不变 |
| 挑衅者非驻扎/驻扎 | 条件加成为0/+20；保持驻扎到下一己方回合仍恢复满血 |
| 谋划新目标，第一次和平→战争 | 一次+1000，重复事件不再发；持续战争每回合+100 |
| 和平→再战同一目标、旧档已奖励目标 | 不重复首次奖励，和平期间持续收益停用 |
| 铁血军团及重复升级/重载 | 原适用范围一次+20战斗力、+3移动 |

简单与421版本的原邪教机制对照：三教分配、AI至少3个时三教齐全、5/14科技门槛、目标阶段倍率、各阶段对玩家效果和魔偶原+10/+20保持。单独记录本次魔偶故障修复。

困难、疯狂各测试三教和三个阶段。具体数值见工作区 Reports/rc390-normal-balance/report.md。升阶段时检查旧阶段原生门控失效、仅当前阶段生效，新增城市/单位继承该阶段；人类、城邦、蛮族、自由城市没有新增加成。被缚者单位离开/进入己方领土以及地块所有权改变时，检查额外战斗力是否随当前所有权变化。

倒吊人回血以该AI自己的回合开始为准。检查受伤、满血、死亡和文职单位；重复同回合/保存重载只一次，不恢复移动和攻击次数。维护费优惠按实际单位金币维护费百分比返还金币；原生维护费行不会被改为百分比。用日志中的 base、percent、refund 和实际金币差值核对，零/负维护费不得获得返还。确认 Gameplay 的 GetUnitMaintenance 可用；若日志出现 NO_NATIVE_GET_UNIT_MAINTENANCE，该环节没有结算，需要继续修复。

魔偶只在倒吊人阶段2/3出现，沿用实际近战单位模型，显示“血肉魔偶”和专属旗标；保持单位ID、经验、晋升和编队。检查当前最高通用近战单位及其文明专属替代单位，旧型号、远程、骑兵、人类不被误标。旧档一次修复只补当前基准候选，日志应有 index repaired/marked，后续不再全军补扫。刚生成时对象尚不可查询的候选由地图事件补捕获，下一同步回合处理；联机需跨完整世界回合并在稳定锚点处理。测试候选处理前死亡/转移、刚生成即保存重载、阶段2→3的+10替换+20和主动攻击信仰扣除。

多人使用两台真实客户端，同一主机设置开局。核对两端 LOTM_CULT_DIFFICULTY、三教阶段、当前资格、维护费回执和魔偶单位ID/能力/登记表。保存重载、重连和连续两个AI回合均需留双端日志，确认无OOS。当前尚无本版本实机或双客户端结果。

# 三神祝福实机验收｜rc.392 / 资源424

离线测试和发布检查不代表以下项目已经在游戏中通过。不要自动启动游戏、操作奖励或结束回合；由用户载入有效普通存档后观察。

1. 启动日志出现 `[LOTM][GodBlessings] initialized normal=1`；普通模式事件提示列左侧出现用户雷霆徽章，次数为同步Property中的值。中文/英文均应一致；救赎模式不加载新按钮、动画和新武器定义。
2. 获得黑夜或愚者的FULL/HALF祝福时，在当时首都地图位置播放一次红月黑雾或黄金眼动画；数值、持续回合及愚者科技/市政尤里卡规则仍按原祝福。神器奖励不播放祝福动画。保存重载、重复发布事件和反复开教会面板不重播已完成动画。
3. 获得风暴FULL/HALF祝福各增加1次释放机会，不再获得旧临时军力、经济或海军回血。永久使者收益继续保持。机会可留到以后使用，同一档同一任务不能重复增加。
4. 点击徽章进入原版核武选点页面，查看合法目标和爆炸预览，再确认。专用取消按钮不扣次数，原版取消确认后可以继续瞄准或取消；反复点击与取消不生成额外机会。
5. 成功投放后记录确认目标、原版武器消耗、一次FIRED结算和目标雷暴动画；扣1次，临时投放实体/库存清理。不能只用READY或按钮点击日志认定伤害完成。若不能准备/没有合法目标，次数保留并显示原因。
6. 使用可复现的同一场景对照普通核弹：同样目标与周围1格内单位、城市防御/人口、区域/建筑、改良及资源/道路；包括核防护与防空等原版阻挡情形。逐项比较实际损伤。新武器复制普通核弹的损伤开关和半径，使用原版WMD_STRIKE；自定义武器类型与引擎结算的实际等价性仍需这个对照。
7. 投放前后核对7格的原生核辐射状态/剩余回合，确认零新辐射，不清理其它来源的既有辐射；持续到下一回合再次确认。FalloutDuration=0定义检查不替代实测。
8. 旧档仍有效的风暴临时祝福只转换1次机会并撤去那一份旧增益；已过期旧祝福不补机会。再保存重载不重复撤去/补发。既有黑夜、愚者历史奖励不为动画重新发奖励。
9. 在瞄准中保存重载、跨回合或显化对象失效：未投放不扣次数，已消耗的原版库存只结算一次。首都位置/空中容量、临时显化和新武器类型的原版许可需要实机确认。
10. 双客户端使用同一普通存档核对奖励次数、CastSerial、TargetPlot、武器库存、临时单位ID和SettledSerial及OOS日志。离线Lua协议回归没有验证实际网络传输、单位创建或核武结算。

# rc.347／资源379：偷盗者序列4建城

## 修复

救赎偷盗者持有者曾在数据库无条件`FoundCity=1`，原版建城按钮绕过已有序列检查；自定义营地按钮仅列入Files、未实际注册。现在持有者类型关闭原版建城，救赎模式正式加载“寄生蛮族营地”动作。

序列9—5不可用；序列4—0必须由存活持有者站在蛮族营地上提交同步命令。Gameplay再次检查模式、途径、序列、本人持有者、位置和请求状态。专用临时原生建城单位保留游戏的地形／距离判断，不能训练，不与时之虫混用。

仅匹配真实CityBuilt后消费持有者，沿用五回合复活；序列4获得本阶段消化，更高序列只继承技能。失败清理临时单位，持有者保留。成功回调不手动销毁正在执行原生操作的临时单位，避免原生回调重入风险。

## 完全退出游戏后复验

1. 资源379新局和原序列9旧档：偷盗者持有者没有原版“建造城市”按钮，也没有序列4营地动作。
2. 序列5仍不可用；晋升序列4后，持有者站在蛮族营地才显示“寄生蛮族营地”。普通地块、别的单位或敌人单位不显示。
3. 合法建城成功归玩家；持有者消失，5回合后按既有生命周期复活。非合法建城位置／请求失败，不消耗持有者、不增加消化、不留下临时单位。
4. 序列3—0仍可继承营地建城，但不获得序列4消化。序列1真时之虫同格时不触发额外建城消化、恢复或冷却；两种建城不会互相冒认。
5. 同回合连续点击、保存重载，不能重复建城／消耗／记分。分别验证单机、独自多人房间与双客户端。

现有城市不回滚，不因曾经误用序列9原版按钮而删除城市。数据库与Lua模拟通过不代表实际地图、原生按钮、联网或重连已通过。

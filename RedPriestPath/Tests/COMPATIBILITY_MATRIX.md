## 本轮已执行证据口径

- `Tests/validate.py`：全部工程内静态检查。
- `Tests/validate.py --game-root <本机游戏目录>`：在前者基础上核对 Firaxis schema、
  侦察资源、模式 Modifier、事件签名、纵火效果 API、Lens 和世界文字 API。
- Python `compile()`：验证 `validate.py` 与 `build_release.py` 语法，不生成 `.pyc`。
- 发布构建脚本：仅在上述检查完成后生成 zip、文件清单和 SHA-256。

静态审计只说明接口与打包候选合理，不能替代游戏引擎加载或联机认证。

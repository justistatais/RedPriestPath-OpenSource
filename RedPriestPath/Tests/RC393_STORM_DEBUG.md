# 资源425｜风暴临时无限调试

普通模式按钮无需祝福即可使用，显示“∞”，提示带“调试模式”。每次仍通过同步准备、原生核武选点/预览/确认以及库存消费结算；当前回合、首都、合法目标和原生准备限制保留。连续测试不扣正式祝福次数，不补发任何正式祝福。

唯一开关在 `Scripts/LOTM_GodBlessings.lua` 的 `BEGIN TEMP DEBUG STORM_UNLIMITED` 块：

```lua
local STORM_DEBUG_UNLIMITED=false;
-- 临时调试开关：注释下面这一行即可恢复默认次数限制。
STORM_DEBUG_UNLIMITED=true;
```

后续关闭时注释 `STORM_DEBUG_UNLIMITED=true;`，重新生成 Gameplay bundle，并按正常流程升版检查安装；下一次同步启动会覆盖存档内的UI调试标记。UI不另设开关。已准备的调试投放保留逐次标记，即便随后关闭调试并重载，也不会误扣正式次数。

用户重新启动游戏并载入普通模式存档，确认按钮显示“∞”及调试提示，先取消一次，再连续释放两次，核对目标选择、实际伤害、无新增核辐射、雷暴动画及临时实体清理。实机验证可沿用 [424完整验收](RC392_GOD_BLESSINGS_ACCEPTANCE.md)。

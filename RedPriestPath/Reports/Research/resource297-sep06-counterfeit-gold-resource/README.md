# 资源297｜假金币独立资源与标准外交交易

## 玩家侧结果

- 假金币复用既有专属图标，作为独立货币显示在顶部产出栏，展示库存及每回合`+20`／`+40`。
- 标准外交交易的物品清单新增独立“假金币”分组；不再通过途径详情页手动兑换。
- 单机交易生效后，付款方扣除相同数量的假金币，收款方获得相同数量的真金币，比例固定为1:1。
- 偷盗者详情说明改为与其余三条途径相同的累计技能清单，只写技能名称和实际效果。

## 实现与隔离边界

- `RESOURCE_LOTM_TP_FAKE_GOLD`仍是玩家可见且权威的假金币库存。
- `RESOURCE_LOTM_TP_FAKE_GOLD_TRADE`仅是原生DealManager可承载的一次性交易载体；正常资源列表隐藏它，交易生效后立即由Gameplay消耗。
- `DiplomacyDealView_LOTM_TP.lua`只在普通模式导入，并在`GameConfiguration.IsAnyMultiplayer()`为真时完全停用；`LOTM_TP_Thief.lua`再次以`IsNetworkGame()`拒绝结算。
- 没有修改`LOTM_MP_TurnSync.lua`、Quick Deals兼容层或任何外部模组。Quick Deals不提供本次新增的独立假金币栏目。

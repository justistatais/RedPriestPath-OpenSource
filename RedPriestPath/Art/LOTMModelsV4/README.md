# 七元素体、圣者与天使游戏资源

资源406 / rc.374。七元素体V4、白金圣者V4和天使V1经独立游戏化后，覆盖9个神明/外神单位及3教会各自的圣者、天使，共15个单位类型。错误先生沿用完美者，外神仆从沿用外神缩小版；本轮没有额外新建这两个造型。

`LOTM_MODELS_V4_ART`仅在救赎模式加载，LoadOrder 205覆盖旧204美术。原有V3、圣者/天使代理资源保持完整；最终绑定显式清空ProxyUnit，并将每单位成员替换为一个自定义人物。没有改变单位属性、战斗规则、脚本同步或救赎专用逻辑。

七元素体沿用原有GDR骨架的Root绑定；圣者和天使适配原生Missionary骨架与行为。圣者38,000三角面，天使本体38,000加光效18,000；每顶点至多4个骨骼权重。发须使用原发流抽样生成的几何发束；原始高精度Blender工程未覆盖。

天使保留冠环、头环、背环、双层光翼轮廓、地面法阵与亮点；单位自发光材质及UV滚动速率0.16构成流光。Blender独立物体的光圈旋转、翅膀轻摆、光粒浮动曲线没有转换成游戏动画；透明羽膜省略，保留发光羽线。人物继承原生动作。此版本不宣称完全复现Eevee光效。

资源405实机反馈天使出现亮绿/紫色异常。复核发现旧图集仅判断默认值为1的Emission Strength，误将21块不发光的人物材料写成自发光。本轮按原始发光颜色修正圣者与天使图集，并把RGBA8输入的Normal/AO/Metalness/Gloss恢复到完整材质；本体最低发光权重改为0，光效为1。七元素体材质保持资源404原样。黑TintMask继续阻止阵营染色；打包后底色与发光图已解码校验，但实际异常是否消失仍待游戏复核。

已通过9模型CN6→FGX→CN6往返检查、骨骼层级/位置/三角面/权重检查、人物合成姿态检查和Windows/MacOS Cooker。`manifest.json`列出资源哈希与往返数据。Cooker仍有原生GDR多track-group警告，与旧资源链一致。

尚待实际游戏检查：新局/旧档重载后的模型大小、人物行走和战斗动作、握杖、极端姿态衣物穿插、昼夜发光与多单位性能；双端玩家须使用相同资源406。结构和Cooker通过不等于实机或多人通过。

人体和发须署名见[原型来源](Saint_Source_Credits.md)。游戏适配新增了Firaxis原生骨架和行为引用，仅供文明VI模组使用；原型来源文档中的“未混入游戏提取网格”描述的是原型交付阶段。原模型、游戏化脚本、工程、预览和失败证据保存在项目的`Civ6_3D_Modeling/work/game_integration_v4_20260926/`。

本轮12个角色/城市FGX与此前逐字节相同，未改人物骨架或三角面。完整材质、颜色误差与未发光单元检查绑定于最终BLP哈希：`../LOTMArtMaterialAudit_rc374.json`。修正版工程、Blender预览和失败证据保存在`Civ6_3D_Modeling/work/art_fix_rc374_20260926/`；这些预览不是游戏截图。

# 诡秘之主单位与玩法

版本 `0.1.0-rc.233`（资源版本265）是面向《文明 VI：风云变幻》
`RULESET_EXPANSION_2` 的三途径候选，三条途径均开放序列9–0。它已完成工程内静态集成和本机原版文件
引用核对，但尚未完成真实游戏内与双客户端验证，不能标记为“多人验证通过”。

## MVP 内容

- 高级设置可选“拯救模式”：勾选后生成中央封印区及愚者、黑夜、风暴三个预定中心的同步坐标和四块各19格预留区；所有人类玩家从开局起持续实时看见这76格，普通模式不加载该逻辑。
- 六类教会守卫使用独立圆形图标：愚者近白底、黑夜教会紫底、风暴教会青底，统一叠加黑色教会纹路。每座教会开局仅有1名圣者；以后每10世界回合每座教会最多新增1名守卫，依次补至每教会3名圣者／1名天使上限，死亡补充也占用同一节拍。圣者战斗力90／移动力3，天使战斗力130／移动力4；守卫每回合同步按自身移动力优先追击并清除失控魔物，其次处理不驻营的游荡普通蛮族，不攻击或清除营地／工坊，不主动攻击玩家／正常AI，也不能占城。资源236修复资源219以来全部守卫移动请求因Gameplay缺少UI侧原生操作API而失败的问题。

- 资源181的救援模式把营地目标提高为每个存活主要文明6座；低于目标时，每世界回合同步建立最多10个具有部落记录和守军的完整营地，同时把救援专属原版自然生成参数提高到100、每文明上限10。游走魔物全图活体上限提高到60；普通模式仍使用原有营地和魔物参数。

- 资源182为同步清怪移动增加目标周围1–6环的确定性空地兜底：教会守卫或锁定AI城市的失控者在本地没有严格接近目标的合法地块时，不再永久重复`NO_PLOT`。失控者重部署仍只允许无主地或非人类主要文明领土，不能进入玩家领土；目标锁定不重抽。

- 救赎模式AI陆海空战斗单位决策倾向为100、军事单位生产力+50%、军事单位金币购买-30%；每个非人类主要文明仍实行15个战斗单位硬上限，旧档超额单位按UnitID从新到旧退役。Phase8每世界回合只协调一次，Phase5每回合只扫描一次补营候选，高频逐单位日志默认关闭；路径兜底扩大到目标周围12环。普通模式不受这些救援专属规则影响。

- 资源184新增同步净化贡献榜：文明、城邦与愚者／黑夜／风暴教会分别累计净化值和事件数；旧档首次载入回放既有Phase6事件。HUD显示前三名，鼠标提示列出完整排行。战斗预览补显示出生时期强化，避免总战力与可见条目相差10／20／30／40。

- 资源185把旧档恢复期间的单位处理改为增量：Phase7只给新增邪教AI单位更新阶段能力；Phase9首次迁移建立AI战斗单位索引，之后按单位增删维护15单位硬上限；救援模式的人类单位恢复不再触发AI Cult全局重算。一次性全军扫描只允许出现在有版本Property门控的旧档迁移中，常驻事件不再全扫。

- 资源186为Phase7单位增加持久能力签名：读档恢复遇到相同邪教、阶段和能力结构版本时只重建索引，不再重复查询5种Ability；资源185旧档首次升级只写签名。九个Gameplay单位加入监听器同时启用一次性本地计时汇总，首个玩家回合打印后关闭，诊断值不进入同步Property或玩法判断。

- 资源187把Workshops使用的蛮族PlayerID改为Gameplay会话内一次性缓存；无论解析到真实ID还是`-1`，后续单位加入事件都只比较整数，不再为数百个非蛮族恢复事件重复跨C API枚举。缓存不写Property、不引入迁移或常驻全扫。公开大型模组研究同时确认：静态单位规则优先数据库化，动态状态采用单位键索引和增删事件维护，不能照搬无条件读档／逐回合全军重建。

- 资源188把旧整秒`os.clock`探针替换为优先使用`Automation.GetTime()`的高分辨率诊断，并在日志打印计时器来源。九个UnitAdded模块继续分别计时；Workshops额外测量初始化地块扫描、首个蛮族回合地块扫描、蛮族全军维护和总计，并记录营地／单位数。所有探针只更新本地Lua表，报告后关闭，不写Property、不调用随机、不改变Gameplay结果。
- 资源189针对资源188实测的读档热点建立工坊索引：首次升级只扫描全图一次，持久保存有序工坊PlotIndex；以后读档只从登记表建立会话半径3覆盖，UnitAdded在唯一覆盖时O(1)定位，范围重叠时仍走旧解析器保持原选择顺序。营地新增／分类／移除增量维护登记，蛮族回合只遍历登记工坊。Phase9消化的BASE／LOST元数据只在缺失或变化时写，玩法与奖励规则不变。

- 每个AI主要文明会被同步且永久分配魔女、倒吊人或被缚者邪教；AI不少于3个时优先保证三教齐全。三教分别共享独立的1／2／3阶段，所属AI中任一文明完成5／14项工业及以后科技时永久升级。魔女压制得分第一文明；倒吊人与被缚者仅在战争中压制已选择正式途径的人类。所有效果按双方阶段使用1／0.2／0／2／3倍率，每个阶段只执行本阶段明文技能。

- 倒吊人二、三阶段新训练的当前主力近战单位会被等价标记为“血肉魔偶”，保留原模型、经验、晋升、军团和AI任务并固定获得基准+10／+20；单位旗帜只换为用户提供的新魔偶标志，完整保留所属文明原版旗帜颜色。已接触AI的外交情报主页显示其所属教会、共享阶段和当前技能说明。

- 原版城邦页面固定增加愚者、黑夜女神、风暴之主三座无城教会。它们使用原版未分配使者资源和独立1／3／6效果，不生成地图城市且没有宗主国；6／10／15使者依次发布失控工坊或失控魔物神谕任务。

- 高级设置新增“《诡秘之主》模组语言”：默认简体中文，也可在开局前选择English。该选项控制本模组的项目、政策、单位、按钮、封印物页面及12页说明书；开始游戏后固定，不要求改变文明VI客户端的全局语言。

- 12页《诡秘之主》游戏说明书顶替风云变幻新内容介绍并保留原版翻页模板；每个新对局自动显示一次，使用独立的“不再自动显示”选项，绝不读取或改写官方风云变幻介绍的隐藏状态。原“风云变幻新内容”菜单入口可随时重新打开说明书。

- 三途径详情页右下角提供“查看介绍”，可直接打开同一套12页说明书；左上角封印物入口使用独立金色眼睛图标。

- 联机代码边界遵循官方情景脚本模式：UI只读并通过同步 `EXECUTE_SCRIPT` 提交请求，Gameplay复核后写入状态；随机数只在Gameplay使用同步随机源。封印物与工坊回合处理按首次激活／回合号去重，以覆盖保存重载和掉线重连边界。

- 全局失控工坊、魔物与封印物：普通模式的营地首次同步抽取普通/工坊各50%，仍按创建世界时代固定等级；救援模式按五时期使用80／85／90／95／100%工坊率及85/15/0、60/30/10、35/40/25、15/40/45、5/20/75的低／中／高阶分布。Phase5在营地低于存活主要文明数×6时每世界回合同步补最多10个完整部落，只用当前时代合法的普通蛮族单位。救援模式游走疯狂者全图最多同时存活60只、每工坊最多4只；每个世界回合由同步锚点主动选择4座工坊各尝试1次，不再等待普通蛮族先刷兵。疯狂者从当前合法单位与同大陆非人类主要文明城市中同步随机锁定目标，目标消失前绝不换目标；锁城后可穿过非人类AI领土，距城6格内卡路时重部署到合法邻格继续攻城。玩家、城邦、自由城市或封印城永远不是城市目标。低／中／高阶中央失控者和游走魔物分别冻结为当前近战基准B+30／B+40／B+50，再叠加出生时期强化。人类清除工坊后由同步Property账本获得21件全局唯一封印物之一。
- 救援模式普通AI仍以原生生产和购买获得军队，不免费生成单位。军事单位生产补偿现为+50%，金币购买-30%，陆海空军事决策权重为100；旧+100%生产与-50%购买数值继续仅作为注释历史保留。

- 每名人类主要文明玩家可独立选择 `NONE`（默认）、`PATH_RED_PRIEST`、`PATH_PERFECT` 或 `PATH_BLACK_EMPEROR`；选择后三条Gameplay逻辑严格互斥，AI不参与。
- 完美者序列9–0：在既有通识、考古、鉴定、机械、天文和炼金能力之上，序列3令所有专业区域及其建筑的六项直接产出+60%；序列2自动触发所有未完成科技/市政的尤里卡与鼓舞；序列1一次性获得99999大科学家点数并使城市科技、文化+30%；序列0使所有城市六项基础产出+100%。
- 三条途径持有者共享专属晋升树：左路战斗爽1/2分别+10/+15基础战斗力，战斗爽3提供相邻一格己方战斗单位+10战斗力的战争光环（不含平民与本人）；右路跑路王1/2/3分别+2/+3/+4移动力。每条分支逐级解锁。
- 黑皇帝序列9–0完整实现规则漏洞至“9座陵寝的故事”。序列1解锁可重复“转化”项目（生产力同时100%转科技、100%转文化、200%转金币）、混乱Ⅲ、堕落Ⅲ和令交战主要文明六项城市产出-50%的狂乱Ⅱ；序列0永久增加3军事、3经济、3万能政策槽，并使用紫色王座标志播放专属登基过场。强权仍采用普通对战战斗力+10，不改变面板基础战斗力或平民单位类别。
- 完美者使用九项独立魔药/升格项目推进9→0，沿用合计6点、每回合最多2点、晋升清零的统一消化规则。
- 唯一途径英雄、晚时代生成、科技战力随原版近战链20→35→45→55→65→75→85、
  阵亡后 T+5 复活，以及经验、
  专属晋升和老兵名恢复。
- 序列 9 猎人以途径持有者的经验增长事件消化；序列 8 挑衅者、序列 7 纵火家；
  每序列只看合计 6 点，不要求两类各 3 点，每玩家每回合上限 2。
- 新增对任一已选途径生效的万神殿“建立教会”，每3回合自动提供1点当前序列消化；
  创始人信条“建立真神教会”同样对任一途径每回合提供1点消化。三条途径晋升序列0时，已建立真神教会使用正常成本仪式，未建立则使用生产力需求翻倍的无圣仪式。
- 成本 60/100 的两项魔药项目与 9→8→7 晋升、计数清零和旧技能继承。
- 序列7→0的七项新增魔药/祭典项目；红祭司从序列6开始继承阴谋家能力，可选择存活主要文明作为谋划目标，首次与目标开战获得2000金币，战争期间通过原版每回合金币Modifier获得100金币，
  序列5击杀恢复，序列4全军+30战斗力与+3移动力，序列3战争时所有城市生产力+100%，
  序列2天气操纵，序列1全军绕墙，以及序列0战争时所有城市总生产力达到和平时10倍。
- 完成任一途径的序列0最终项目后，顶部途径入口会保留未播放状态；玩家第一次点击该入口时播放
  对应途径的专属晋升过场，过场显示后再点击才打开详情页。红祭司使用红色标志和四行尊名，
  完美者使用金色标志及三行尊名，黑皇帝使用紫色王座标志及四行尊名。同一路径标志也作为顶部入口图标，
  使用40像素控件承载居中的32像素图案，以露出外围圆环。过场标志根据分辨率选用与控件
  完全同尺寸的居中纹理，避免偏移裁切；过场不会自动结束，点击底部“继续”后才同步确认
  并淡出关闭，点击背景或按Esc均不会关闭。
- 序列 7 纵火：只能选择可见、六角距离6内、非城市中心且存在交战敌军的陆地格；
  直接消灭格内全部敌方单位，不影响城市及非敌方单位，并耗尽移动、进入T+5冷却、
  留下九回合无持续伤害的燃烧标记。
- 本地玩家只读详情页只显示总进度，不显示内部单位ID，也不单列途径持有者状态或纵火
  冷却状态；英雄定位按钮和纵火按钮自身仍按实际状态工作。底部按当前序列到旧序列的顺序
  完整列出所有已继承技能作用；
  主动纵火与谴责计数严格经过同步脚本命令并在 Gameplay 端校验。

## 安装与启用

1. 解压后确保目录结构为
   `...\Documents\My Games\Sid Meier's Civilization VI\Mods\RedPriestPath\RedPriestPath.modinfo`，
   不要多套一层发布包目录。
2. 在“附加内容”中启用本模组。
3. 以“风云变幻”规则集创建新游戏；需要英文时，在“高级设置”把“《诡秘之主》模组语言”改为English，默认保持简体中文。
4. 进入地图后，每名人类玩家会在首回合独立选择“红祭司途径”、“完美者途径”、“黑皇帝途径”或“本局不启用”。

完整安装、升级、卸载和故障日志说明见 [INSTALL.md](INSTALL.md)。

## 开发验证

在包含 `RedPriestPath` 的目录执行：

```powershell
python .\RedPriestPath\Tests\validate.py
python .\RedPriestPath\Tests\validate.py --game-root "D:\app\steam\steamapps\common\Sid Meier's Civilization VI"
```

第一条检查工程结构、XML、最小 SQLite 外键、引用、Type 唯一性、版本、发布卫生和
UI/Gameplay 同步边界；第二条额外核对本机 Firaxis schema、资源和 Gameplay/UI API
用例。发布包可重复构建：

```powershell
python .\RedPriestPath\Tests\build_release.py
```

Gameplay 运行日志前缀为 `[LOTM_RP][Lifecycle]`、`[LOTM_RP][Progression]`、
`[LOTM_RP][Arson]`、`[LOTM_RP][Advanced]` 和 `[LOTM_PP][Perfect]`。阶段 01 探针在发布副本中固定关闭，只允许在开发副本临时开启。
